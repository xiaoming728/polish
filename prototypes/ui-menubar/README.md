# PROTOTYPE：菜单栏 + 预览面板 + 小提示 + 设置界面（一次性代码，不合入 main）

回答「预览面板、小提示与设置界面的形态」（issue #8）：这些界面分别长什么样、怎么操作？

## 运行

```sh
./run.sh          # 编译并启动；菜单栏出现魔杖图标，屏幕底部出现原型切换条
```

退出：菜单栏图标 → 退出 Polish。

## 怎么看

- **按 ⌥P**（任何应用里）：唤起润色。数据是假的，不读选区、不发请求、不回填。
- **面板变体**：点底部切换条的 ◀ ▶，或者在面板聚焦时按 ←/→ 切换。
  - **A 跟随光标紧凑浮层**：出现在光标旁，只突出结果，原文折叠起来，底部一行快捷键提示。原型用鼠标位置代替输入框的 caret。
  - **B 居中原文/结果对照**：屏幕中央的大面板，顶部是配置标签（⌘1–3），中间左右对照原文和结果，底部是按钮。
  - **C 顶部 Spotlight 横条**：屏幕上方的宽横条，结果用大字单栏显示，原文压缩成一行，配置用下拉菜单选。
  - 小提示也随变体变化：A 是光标旁的胶囊，B 是右上角通知卡片，C 是顶部居中的 HUD。
- **面板里的操作**：⏎ 替换（终端场景下写回输入框）；⌘C 复制；Esc 放弃；⌘1–3 换配置重跑；润色中再按 ⌥P 取消；⌘, 打开设置。
- **菜单栏菜单**：
  - 润色 / 取消
  - 当前配置（勾选）
  - 回填方式（预览 / 自动替换 / 小提示确认）
  - 设置…
  - 原型专用：「演示场景」切换 GUI 输入框、终端 Claude Code、请求失败、回填前校验失败、未选中文字
  - 原型专用：「面板变体」
- **设置界面**：四个标签页。
  - 配置：列表加表单，包括预设服务商、Base URL、Key、模型手填或拉取、润色指令、额外请求体 JSON、测试连接。
  - 通用：快捷键录制（真的会重新注册，冲突时保留原快捷键）、回填方式、超时说明。
  - 终端集成：zsh 片段和 alias，带一键复制。
  - 权限与隐私。

## 自检

`build/polish-ui-prototype --demo a|b|c [settings]` 会在启动后自动唤起对应变体（以及设置窗口），用于截图，不发送合成按键。

## 浮层动效对照（OverlayMotion.swift）

```sh
./run.sh motion --dark      # 或 --light；--reduce 模拟「减弱动态效果」；--en 看英文文案
```

一个舞台窗口左右两栏：左「改前」照搬现有的 TypingHintView / PanelView / ToastView，右「改后」是视觉统一、出现消失动画和等待流光的新写法。两栏共用假数据，按脚本循环播放：逐键拼音（不应有动画）→ ⌥1 / ⌥2 结果 → 淡出 → ⌥P 等待（光边旋转）→ 流式（光边减半）→ 完成（图标弹一下）→ ⌘2 重跑 → 校验失败（提示条晃一下）→ 已替换胶囊 → 请求失败（光边橙色闪一下）。录像不入库，存放在 `~/Movies/polish-overlay/`。
